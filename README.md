# imgCheck

Windows 전용 유틸리티: 특정 프로세스 창을 캡처하고 `img/` 폴더의 이미지들과 템플릿 매칭하여 동일한 부분이 있는지 검사합니다.

## 사용법

1. 의존성 설치:
```
pip install opencv-python numpy pillow psutil pywin32
```

2. `img/` 폴더에 비교할 이미지(템플릿)를 넣습니다. (png, jpg, bmp 등 지원)

3. 실행:
```
python script/imgcheck/imgCheck.py
# 또는
python script/imgcheck/imgCheck.py --pid 1234
python script/imgcheck/imgCheck.py --name chrome
```

4. 결과:
- 템플릿이 화면에 있으면 Windows 알림창으로 PASS를 표시합니다.
- 없으면 FAIL 알림을 표시합니다.

## 옵션
- `--img-dir`: 이미지 폴더 (기본: `img`)
- `--threshold`: 템플릿 매칭 임계값 (기본: `0.9`)
- `--no-feature`: 템플릿 매칭 실패 시 특징 기반 매칭(ORB) 시도를 비활성화합니다
- `--auto`: `--name` 검색 시 탑-레벨 창들 중 visible한 첫 번째 창을 자동으로 선택합니다 (대화형 선택 건너뜀)

추가 매칭/전처리 옵션:
- `--scale-min`, `--scale-max`, `--scale-steps`: 템플릿 매칭 시 탐색할 스케일 범위 및 단계 수 (기본: `0.5` ~ `2.0`, `121` 단계)
- `--upsample`: 작은 템플릿에 대해 2x 업샘플 버전을 추가하여 작은 대상의 검출을 향상시킵니다
- `--use-edges`: Canny 엣지 기반으로 전처리하여 엣지 중심 매칭을 시도합니다
- `--canny-th1`, `--canny-th2`: Canny 엣지의 임계값을 지정합니다 (기본: `50`, `150`)

특징 기반 매칭 옵션:
- `--feature-method`: 특징 매칭 알고리즘 선택 (`orb`, `sift`, `akaze`) (기본: `orb`)
- `--orb-nfeatures`: ORB 검출기 특징 수 (기본: `5000`)
- `--orb-ratio`: ratio test 비율 (기본: `0.75`)
- `--orb-min-inliers`: homography inliers 최소 기준 (기본: `8`)

참고:
- 작은 템플릿의 경우 스크립트가 자동으로 업샘플된 변형을 생성하여 더 정확한 매칭을 시도합니다.
- `--no-feature`가 설정되면 특징 기반 매칭은 완전히 건너뜁니다.

창 기반 선택
- `--name` 옵션을 사용하면 이제 프로세스 리스트 대신 **탑-레벨 창 목록**(PID, HWND, visible, 제목, 프로세스 이름)을 보여줍니다. 창 제목을 보고 원하는 창을 선택하면 더 정확하게 타겟을 지정할 수 있습니다.

디버그 이미지:
- 캡처 및 매칭 결과는 `debugimg/` 폴더에 자동 저장됩니다. (capture, match, feature 결과 등)
- 기본적으로 디버그 로그 및 저장 메시지는 기록되지 않습니다. 자세한 디버그 출력(파일 저장 메시지 포함)을 보려면 `--verbose` 옵션을 사용하세요.
## 변경 사항 (2026-01-05)
- `--no-feature` 플래그가 제대로 적용되지 않던 문제를 수정하여, 설정 시 특징 기반 매칭을 완전히 건너뜁니다. ✅
- 기본 스케일 탐색 범위를 더 넓게(0.5~2.0) 하고 스텝을 촘촘히(기본 121) 늘려 작은/큰 템플릿에 더 강건해졌습니다. 🔧
- 작은 템플릿에 대해 자동 업샘플링(2x)을 추가해 작은 이미지 검출 정확도를 개선했습니다. 🔍
- Canny 엣지 전처리 옵션(`--use-edges`)을 추가하고, 임계값 조정 옵션(`--canny-th1`, `--canny-th2`)을 노출했습니다. ⚙️
- ORB 관련 파라미터를 노출(특징 수, ratio, 최소 inliers)하여 튜닝이 가능해졌습니다. 🛠️
- 변경 사항을 반영한 새로운 exe를 빌드했습니다 (`dist/imgCheck_20260105.exe`).

GUI 추가 (2026-01-05)
- `python.py`에 간단한 GUI를 추가했습니다. 실행하면 창이 열리며 `실행 시간(초)`, `입력할 키`, `간격(ms)`를 입력할 수 있습니다.
- 모든 텍스트칸이 채워져 있고 값이 유효할 때만 `시작` 버튼이 활성화됩니다. 시작 중에는 `종료` 버튼으로 프로그램을 종료할 수 있습니다.
- ESC(전역)를 누르면 즉시 중지됩니다.
- `시작 키(핫키)` 입력칸이 추가되었습니다 (기본: `F5`). 이 키를 누르면 백그라운드에서 프로그램을 시작/중지(토글)할 수 있습니다.
- 녹화/재생 기능 추가 (2026-01-06):
  - `녹화` 버튼을 눌러 10초간 마우스/키보드 동작을 녹화하고, 완료 후 JSON 파일(`.json`)로 저장합니다. JSON에 메타 정보(타임스탬프, recorder_version, 화면 해상도)가 추가됩니다.
  - 레거시 텍스트 파일(`.txt`)을 선택하면 자동으로 JSON으로 마이그레이션되어 저장 및 선택됩니다(자동 마이그레이션).
  - `스크립트 파일`에서 저장한 JSON(`.json`)을 선택하면, `시작` 버튼 또는 별도 `녹화시작` 버튼으로 해당 스크립트를 재생할 수 있습니다. `녹화시작`은 별도의 단축키로 매핑 가능합니다.
  - 재생은 파일에 기록된 시간(밀리초 기준)을 그대로 따라 수행되며, 재생 완료 후 자동 종료합니다.
- GUI 실행: `python run.py` (별도 옵션 없음)

## 주의
- 본 스크립트는 Windows 전용입니다.
- 화면 캡처는 창이 화면에 보이는 상태여야 합니다.
- 자동화 및 테스트 목적으로만 사용하세요.
